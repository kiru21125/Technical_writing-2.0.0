# Provisioning - Overview
User management is a key function for every business. Provisioning users to your applications, syncing user accounts, and assigning polices are essential. As an organization expands, it becomes tedious for the org owner to do certain operations as every user onboards. This includes operations like providing permissions to users, assigning apps, changing permissions, assigning them to groups, and so on.

### How does Provisioning help your organization?

To automate the process of manually managing users in an organization, we integrate Zoho Directory and third party applications using SCIM to make it easier for the admin to provision user accounts across various applications, thereby reducing errors.

### What is SCIM?
SCIM stands for System for Cross-domain Identity Management, which is a standard for automating the exchange of user identity information between identity providers.
 
## What is SCIM Provisioning?
SCIM provisioning allows you to manage user information efficiently, and to easily add or remove users within the organization across various applications.
 
### How does Provisioning work?
Zoho Directory provisions users and manages user accounts for any app that supports SCIM or has the API for user management. You can also update and deactivate user profiles associated with third-party apps from one central panel.

As all the user profiles are maintained in Zoho Directory, you can manage both third-party apps and Zoho apps in the ZD portal.

With Zoho Directory, you don't need to navigate to other apps individually. Provisioning also helps in the onboarding and offboarding users. For example, even if an employee leaves an organization, they will automatically be deactivated in ZD and the associated user account in all the apps will also be deactivated.

Implementing this protocol also helps in user provisioning, creating, updating, and deleting user accounts in multiple applications.
